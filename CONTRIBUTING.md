# Contributing

## Tests

`python3 -B -m unittest discover -s harness/tests` runs the suite offline, with no fixture, no agent and no network beyond localhost; CI runs it on every push and pull request to main.

## Experiments, scenarios and records

A run's settings live only in its experiment file (docs/USAGE.md, The experiment file); change one there and say why in its `status`.
Scenario edits, version bumps and CHANGELOG.md lines follow docs/SCENARIOS.md.
Commit the batch records `bench.py run` copies into `records/`, with `records/INDEX.md` regenerated by `bench.py index`.
`stream.jsonl`, `stderr.txt` and the per-cell directories carry session identifiers and stay under `RUNS_DIR`, never in git (.gitignore).

## Sign-off

Every commit needs a Developer Certificate of Origin sign-off, as in jaegertracing/jaeger:
`git commit -s` appends `Signed-off-by: Your Name <you@example.com>` with your real name.
